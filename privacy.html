Privacy policy

Last updated: 1 November 2026

Personal Assistant is a private tool used only by its owner. This page describes what it does with Google user data.

What it accesses

One read-only Google permission, granted by the owner: https://www.googleapis.com/auth/calendar.events.readonly. It reads the owner's own calendar events. It has no permission to create, change, or delete events, and requests no other Google data.

How it is used

Event details (times, titles, and the like) are used in two ways:

  • to build the owner's daily briefing, which is assembled on the owner's laptop and delivered to their private Telegram chat;
  • to answer the owner's own questions about their schedule. For this, the relevant event details are sent to Anthropic's Claude API, the language model the assistant uses, and the answer is delivered to the same private chat.

Where it is stored

The Google authorisation token and the assistant's records are stored only on the owner's laptop, in a private directory. They are not uploaded to any server operated for this app.

Sharing

Google user data is not sold, not used for advertising, and not shared with anyone other than the services named above, which are used only to deliver the owner's own messages to the owner.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the assistant's data directory removes everything it has stored.
