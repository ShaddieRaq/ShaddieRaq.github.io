Privacy policy

Last updated: 1 November 2026 (revised to cover Tasks, calendar changes, Gmail, Drive, Sheets and Docs)

Personal Assistant is a private tool used only by its owner. This page describes what it does with Google user data.

What it accesses

Four Google permissions, granted by the owner:

  • Calendar events (calendar.events): reads the owner's events, and can create, change or delete an event only after the owner approves that one specific change in their private chat.
  • Google Tasks (tasks): keeps one task list, named "Assistant", in step with the owner's to-do items. It does not change any other task list.
  • Gmail (gmail.modify): searches and reads the owner's email, saves drafts, and archives, labels or moves email to Trash only after the owner approves that specific batch. It never sends email: drafts are left for the owner to review and send themselves. It cannot permanently delete email.
  • Google Drive (drive): searches and reads the owner's files when asked, and creates new Google Docs and Sheets for the owner. It edits one of the owner's own spreadsheets, adds text to the end of one of the owner's own documents, moves, renames or shares one of the owner's own files, or moves one to Trash, only after the owner approves that specific change (each file to be trashed and each person to be shared with is approved separately). It never changes files owned by other people, and it cannot permanently delete files.

It requests no other Google data.

How it is used

  • The daily briefing is assembled on the owner's laptop from their calendar and to-do items, and delivered to their private Telegram chat.
  • When the owner asks about their schedule, tasks, email or files, the relevant details (for example an event's time and title, or an email's sender, subject and text, or a document's text) are sent to Anthropic's Claude API, the language model the assistant uses, to compose the answer. The answer goes to the same private chat.
  • Google user data is used only to provide these features to the owner. It is not used to train any AI model by this app, not used for advertising, and not sold.

Where it is stored

The Google authorisation token, the to-do items, and a short history of the owner's conversation with the assistant are stored only on the owner's laptop, in a private directory. Email, calendar and file content is fetched when needed rather than copied into storage, although the assistant's own replies, which may mention it, are kept in that local conversation history. Nothing is uploaded to any server operated for this app.

Sharing

Google user data is not shared with anyone other than the services named above, and those are used only to deliver the owner's own information back to the owner. The assistant never sends email. The only way it can cause anyone else to be contacted is through Google Calendar: if the owner approves a change to an event they organised that has other guests, Google notifies those guests of the change, and the approval request says so in advance. Likewise, if the owner approves sharing a Drive file with someone, Google emails that person a link to it.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the assistant's data directory removes everything it has stored.
